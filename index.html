GTA Clip Desk

A personal desktop tool for short-form gaming clips.

GTA Clip Desk is a desktop tool run by one independent creator. It cuts short vertical clips from gameplay livestreams, adds captions and creator credit, and uploads the finished clips to the creator's own TikTok account as drafts, so the creator can review and publish them in the TikTok app.

The tool is not a public service, has no user sign-up, and is not affiliated with TikTok, Rockstar Games or any streamer.
